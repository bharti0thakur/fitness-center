# Fitness Center App

## 📱 Overview

Fitness Center is an Android fitness application designed to help users stay healthy and active through guided workout programs. The app provides categorized workout routines with animated exercise demonstrations and video tutorials. Users can explore different fitness categories, track exercises, and improve their overall fitness journey.

The application is built using **Kotlin** for business logic, **XML** for user interface design, and **SQLite Database** for storing workout and user-related data locally on the device.

## 🗄️ Database

The application uses SQLite Database to store:

- Workout Categories
- Exercise Information
- Exercise Descriptions
- Video References
- User Workout Progress

### Sample Table

| Column | Type |
|----------|--------|
| id | INTEGER |
| category | TEXT |
| exercise_name | TEXT |
| description | TEXT |
| video_path | TEXT |
